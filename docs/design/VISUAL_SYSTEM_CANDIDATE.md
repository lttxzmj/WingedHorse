# WingedHorse 视觉系统：暖金 2D 陪伴绘本

状态：主 Agent 验收修订版 · 2026-08-28

## 验收结论

原交付不予采用：三张手工 SVG 以代码图形模拟角色和场景，不是高保真视觉稿；其中还出现 Emoji 占位，与任务包“不得用临时资产冒充正式交付”的要求冲突。SVG 仅保留为拒收样本，不作为实现依据。

本轮选择用户提供的 Word v2.1 Demo 为问卷流程唯一视觉基线，并在真实 Web 页面落地。角色参考图只用于理解性格、配色和动作，不描摹其 3D 造型。正式方向是圆润、克制的 2D 插画角色，可参考多邻国角色的清晰轮廓和大表情方法，但不复制其资产。

## 核心原则

1. 一个屏幕只突出一个任务：入口负责开始，答题负责选择，结果负责理解并进入养成。
2. 问卷流程不加入产品门户、多 Tab 或功能卡片；选项点击后自动推进。
3. 暖金只承担品牌和主要动作，正文使用深棕，信息不靠颜色单独表达。
4. 角色是视觉锚点，但不挤压题目；正式分层 2D 稿完成前，现有角色只能标记为开发占位。
5. 动效只表达选择确认与页面连续性；减少动态模式下取消位移和庆祝动画。

间距使用 4/8/12/16/20/24/32/40；控件圆角 12、选项 16、结果主卡 24；正文最小 14px，触控目标不小于 44×44px。阴影只使用轻卡片层级，不使用粗黑描边和重压阴影。

## 三个已落地界面

- 入口：窄幅居中，短引子、角色、标题、时长与一个主按钮；无旧产品介绍壳。
- 答题：返回、场景/题数、进度、题干、四个选项；选择后 520ms 自动推进，并提供 4 秒“返回修改”，最后一题直接生成结果。
- 结果：角色优先、类型/稀有度/标语、四维、血统、白描、护理建议、进化图鉴；唯一主动作是“开始进化”。分享、反馈、重测均降级。

## 正式资产与状态

- 八种类型需统一 2D 设定表和授权记录；正面 3/4、侧面、背面；九个基础表情；idle/run/catch/miss/comfort/rest 动作。
- 交付分层 SVG/AI 或 Rive 源文件，足底中心统一锚点；禁止从现有 3D 参考图描摹。
- 掉落物、任务物和场景图标必须使用非 Emoji 正式资产。
- 正常、选择、禁用、加载、错误、空结果、权限拒绝、弱网降级、键盘焦点、减少动态必须有可验证实现。
- 视觉验收必须从当前构建在 375/390/430/768/1440 视口重新截图；旧截图不得作为新版通过证据。
