# AI 伙伴对话页改造验收

日期：2026-08-28  
范围：`/companion` 的移动端优先布局、对话层级、隐私授权与降级回复。

## 发现与取舍

| 原问题                           | 用户影响                             | 已落实的调整                                                                                  |
| -------------------------------- | ------------------------------------ | --------------------------------------------------------------------------------------------- |
| 安全长文与巨大标题先于角色       | 像风险告知表单，不像正在生活的伙伴   | 头部只保留角色名、草原在线状态与 AI 标识；安全说明降为默认可见的一句摘要、可展开完整说明。    |
| 气泡、输入区均使用粗描边大盒子   | 视觉重量平均，首屏没有关系感         | 对话采用轻边线、柔和阴影与单一暖白表面；用户消息才使用暖黄色，避免所有元素抢主色。            |
| 快捷语句横向溢出、输入框占据屏幕 | H5 中容易截断且妨碍继续阅读          | 快捷开场改为完整的两列网格；输入区收为底部粘附的一行文本入口。                                |
| 默认就展示模型/资料发送技术细节  | 用户要“说一句话”时先被迫理解隐私配置 | 默认显示“本次发送范围 · 默认仅此对话”；记忆与生活事实仍保留在可展开、每会话失效的显式授权中。 |
| 未测评时缺少角色身份锚点         | 首屏显得冷且不连续                   | 使用仓库内原创 `wingedhorse-icon.svg` 作为无类型的视觉占位；不会推断用户类型。                |

## 竞品调研如何影响设计

- Sowii 的公开介绍把“角色的日常生活”“写便签、相册、收集物品”作为关系体验，而非单纯聊天；因此本页在有生活事件时提供一条低权重的“它刚刚写下了一件小事”入口，而不是添加新的导航或信息流。 [Sowii App Store](https://apps.apple.com/cn/app/sowii/id6752891135)
- Seedark 将陪伴描述为会记得、会在日常中回应的长期关系；因此把“在草原 · 想和你说说话”的即时状态放在角色名下，并保留用户可控、默认关闭的记忆授权。 [Seedark](https://seedark.ai/zh)

这两点只是交互原则参考。WingedHorse 保持原创 2D 飞马、暖金色品牌系统和本地优先的隐私设计，不复制竞品的角色、UI 或文案。

## 验收结果

- 关键 E2E：`AI disclosure, memory controls and network fallback`、`companion sends life facts and manual mood only after session consent`、`malformed API`、`rate limit` 均通过（移动端与桌面端共 8 项）。
- 视觉检查：已在移动与桌面 Chromium 捕获 `/companion`，检查了安全摘要、可读消息宽度、输入区安全边距与展开授权面板。
- `typecheck` 当前被工作区中与本改造无关的 `apps/web/src/game/DropGameCanvas.tsx:509` Phaser `resolution` 配置类型错误阻断；未修改该并行工作内容。
