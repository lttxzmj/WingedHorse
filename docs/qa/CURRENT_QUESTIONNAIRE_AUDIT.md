# 最新问卷流程验收

日期：2026-08-28

范围：Word v2.1 Demo 对齐后的入口 → 17 题 → 结果 → 开始进化

目标：核心流程可用，移动 H5 与桌面布局清晰，旧问卷数据不混入

## 总体结论

当前问卷主流程通过自动化与目视验收。它已经去掉旧版门户式入口和底部“上一题/下一题”操作区，保持单任务单列结构；点击选项后有 520ms 确认反馈并自动推进，随后 4 秒内可返回修改。结果页按最新版字段展示四维、血统、白描、护理建议和进化图鉴，并补充结果解释与 PNG 分享卡。

正式 2D 角色资产尚未完成，因此截图中的角色只算开发占位，不算最终角色视觉通过。

## 流程步骤

1. **入口｜健康**：标题、题量、娱乐属性和唯一主动作清楚；无旧版产品门户或多导航。
2. **答题｜健康**：场景、题数、进度、题干和四个选择形成单一阅读路径；可返回上一题；选择后自动推进并可短时撤销。
3. **结果｜健康，有一项资产欠账**：信息结构与 v2.1 一致，维度有两端解释、结果规则可查看、PNG 分享卡可生成，主动作“开始进化”明确；页面较长但可用页内导航跳转。角色仍待正式 2D 分层稿替换。
4. **进入养成｜功能健康，视觉待后续专项重构**：结果可进入现有生活主页并继续小游戏；数字生命主页与游戏不在本轮问卷视觉通过范围内。
