# 角色朋友圈改版与验收

更新日期：2026-08-28

## 改造目标

让生活动态从“任务面板 + 系统事件卡片”转成角色本人发布的私密朋友圈：用户进入后先感受到它正在生活，再看到成长进度和产品机制。

## 改造前的主要问题

1. 隐私说明、双标签和大尺寸航线任务占据首屏，动态内容出现得太晚。
2. 航线任务把四个里程碑一次性全部展开，视觉权重高于角色生活。
3. 动态采用标题卡、说明文字和三个大按钮的产品语言，不像角色发出的内容。
4. 事件正文大量使用“它”，用户更像在阅读系统日志，而不是听角色说话。
5. 每条卡片都有边框、圆角、阴影和操作区，重复后产生明显噪音。

## 已落地

- 页面标题改为“它的朋友圈”，强化用户心智。
- 隐私说明压缩为一行状态（如“只保存在这台设备”）+ 隐私入口；不再叠“小世界”标题。
- 导航改为轻量下划线标签，减少胶囊和容器嵌套。
- 航线任务改成默认收起的“共同远行”，需要时才展开里程碑；文案去掉重复的“航线/故事”堆砌。
- 动态改为朋友圈式头像流，以分隔线代替独立大卡片；列表标题只保留“最近 + 条数”，去掉反打卡说教句。
- 页面展示时将事件转换为角色第一人称口吻；访客动态使用单独叙事，避免把访客行为误写成角色本人。
- 最新动态保留场景图片，其余动态采用更轻的纯文字结构。
- 互动改为短按钮“抱住、收藏、回一句”；语义仍对应点赞/共同记忆/对话，并提供明确反馈。
- 保留原有语义标签兼容性、键盘焦点、触控尺寸和减少动态效果。
- 2026-08-29：继续收敛首屏文案噪音，统一操作栏三列对齐，收紧标题与区块间距让动态更早出现。

## 自动验收

`apps/web/e2e/life-moments.spec.ts` 覆盖：

- 移动端和桌面端标题、第一人称文案与动态列表；
- “抱住这刻”状态和反馈；
- 置顶故事展开及共同远行进度；
- 双端全页视觉截图。

此外，移动端“问卷 → 结果 → 草原 → 朋友圈 → 足迹 → 互动 → 游戏”主流程回归通过。
