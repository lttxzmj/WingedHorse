## 统一验收规则

1. “有文档”不等于完成；必须满足任务包的证据和可执行验收项。
2. 研究中的未确认信息必须显式标为假设，不允许转写成产品事实。
3. 视觉稿必须使用真实资产或明确标注开发占位，不能用 Emoji、手工 SVG 或 CSS 图形冒充正式资产。
4. QA 必须从当前构建走完真实流程，截图经目视确认；自动扫描只能补充。
5. 主 Agent 只接收可以追溯到素材、代码、运行截图或测试结果的结论。

本轮由主 Agent 接管最新版问卷的版本、计分、交互和结果页。旧问卷代码、旧 localStorage 数据和旧结果壳不保留。数字生命、小游戏和正式 2D 角色仍须分别通过领域契约、可玩性和资产生产验收，不能用概念稿标记为完成。
