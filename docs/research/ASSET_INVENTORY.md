## 八种形象的真实差异

参考板呈现八种独立情绪/职业隐喻：焦虑粉、疲惫灰、节能绿、天选金、讲解棕、永动蓝、易燃橙、内耗紫。它们的体型比例接近，因此共用基础骨架在技术上可行；但角、鬃毛、翅膀、手持物、坐姿和身体动态差异明显，不能只换颜色当作八个角色。

建议共用躯干与面部锚点，允许每类替换头部轮廓、鬃毛、配饰、手持物和姿势。最终是否共用一套骨架，要在第一张 2D 正面设定稿完成后做变形测试，不能提前定论。

## 下一批需要用户提供或确认

1. 八种形象的名称与图片一一对应表。

3. 最喜欢与最不喜欢的 2–3 个角色细节，尤其是眼睛、嘴型、翅膀和身体比例。
4. 如已有 2D 草图、线稿或品牌字体，请提供原文件；没有也可从统一设定稿开始。

## 插画生产交付规格

- 先交一只基准角色：正面 3/4、侧面、背面，512×512 或可缩放矢量，透明背景，足底中心锚点一致。
- 图层至少包括 body、head、muzzle、ears、eyes、pupils、eyelids、mouth、mane-front/back、wings-left/right、legs、tail、shadow、accessory/prop。
- 表情：neutral、blink、happy、proud、tired、comfort、curious、surprised、resting。
- 动作：idle、walk/run、catch、miss、give、rest；小游戏另交透明 PNG/WebP 序列或 Rive 状态机。
- 所有道具需独立透明资产，并通过形状与轮廓区分，不依赖 Emoji 或单纯换色。
- 每次交付附授权范围、源文件、导出规范、色板和版本号。

当前素材足以做方向评估和问卷临时角色占位，不足以完成八个可动画 2D 正式角色。第一优先级是完成一只基准角色的 2D 设定与分层验证。
