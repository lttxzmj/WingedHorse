# WingedHorse 产品需求文档

状态：Draft v0.2
更新时间：2026-08-28
首发平台：中国大陆 Web / H5，兼容桌面浏览器，后续可安装为 PWA

## 1. 产品定义

WingedHorse 是一款面向职场人群的“娱乐问卷 + 角色养成 + 现实小任务 + 数字生命陪伴”产品。

一句话价值：先用轻松的方式帮助用户看见当前状态，再用一个有记忆、有回应、不会逼迫用户积极的 2D 飞马角色陪伴日常。

核心表达：等不到伯乐，就自己长出翅膀。

## 2. 产品目标

### 2.1 首阶段目标

1. 用户能在 90 秒左右完成 17 道娱乐问卷。
2. 系统稳定输出四维分数、8 种类型之一及可分享的结果卡。
3. 用户从结果页进入养成主页，完成一次“物品掉落 → 接住/收集 → 入包 → 消耗 → 数值和角色反馈”的闭环。
4. 角色形成温暖、有表现力、可持续扩展的原创 2D IP。
5. 验证用户是否愿意持续回来看“我的牛马今天在做什么”，而不是只使用一次性工具功能。
6. 为后续语音、视频情绪和 rPPG 能力预留清晰的数据与合规边界。

### 2.2 商业目标

- MVP 优先验证问卷完成率、结果认同度、分享意愿和次日回访。
- 养成阶段验证物品循环、现实任务和角色陪伴能否带来留存。
- 商业化暂不进入首个代码闭环，后续候选包括装扮、主题包、深度报告和经过清晰标识的品牌道具。

### 2.3 非目标

- 不提供心理诊断、医疗诊断、治疗或健康监测。
- 不承诺通过摄像头准确判断真实情绪或健康状态。
- 首阶段不做开放式真人社交、B 端管理、交易市场或复杂开放世界；允许私密生活流、AI 牛马访客和封闭式协作任务。
- 不复制多邻国或其他产品的角色、视觉资产、交互稿和文案。

## 3. 目标用户

核心用户为 20–40 岁、使用手机为主的职场人群。他们可能疲惫、焦虑、迷茫或需要倾诉，但不一定愿意使用严肃的心理产品。

典型需求：

- 想用低压力、好玩的方式描述自己的状态。
- 希望被理解，不想被说教或被强迫“变得更好”。
- 喜欢可收藏、可成长、有个性的角色。
- 愿意完成很小的现实任务，但反感连续打卡惩罚。
- 对摄像头、语音和情绪数据敏感，需要明确控制权。

## 4. 产品原则

1. 温暖但不越界：承认用户的感受，不假装懂得一切。
2. 娱乐但不欺骗：测评有结构，结果明确标注仅供娱乐。
3. 休息也是进展：低状态可以进入休养，不制造连续签到焦虑。
4. 主动授权：敏感能力由用户主动触发，拒绝权限仍可完成核心体验。
5. 角色比界面更重要：角色承担情绪反馈，界面保持清晰克制。
6. 数据最少化：不采集完成体验所不需要的数据。

## 5. 核心体验闭环

问卷定起点 → 结果解释 → 获得初始角色 → 进入持续生活场景 → 观察生活事件 → 留言/陪伴/一起玩 → 关系与世界变化 → 再次回来看看。

其中：

- 问卷决定初始类型和四维基线。
- 日常行为只改变养成状态，不静默改变用户的测评类型。
- 类型变更只能由用户主动复测产生。
- 传感器结果只能作为趣味反馈，不能直接下诊断或改变人格标签。

## 6. 功能需求

### 6.1 娱乐问卷

- 首屏的唯一主任务是开测：主文案为“你是什么牛马”，主按钮为“开始测测”；“有一头牛马长出了翅膀”只作为低权重传说钩子，不直接展示天马。
- 采用“打工人的一天”时间线，一次展示一题。
- 共 17 题，其中 16 题参与计分，1 题为娱乐效度彩蛋。
- 答题过程按晨间开机、通勤路上、工位日常、午间回血、下半场、周末与远方、最终坦白局组织为连续章节；章节是叙事提示，不改变题目顺序和计分。
- 选择一个选项后在短确认反馈后自动进入下一题；上一题仍可返回修改，且提供短暂撤销入口。
- 最终坦白局明确标注“不计分”，只作为轻量彩蛋与情绪出口。
- 支持上一题、进度保存、退出后恢复和提交前校验。
- 题目、选项、分值和文案必须数据化，不写死在页面组件。
- 计分规则以 docs/QUESTIONNAIRE_AUDIT.md 为准。
- 结果必须标注“娱乐测评，不构成专业建议”。

验收：

- 17 题可完整作答。
- 刷新页面后不丢失已答内容。
- 相同答案输入始终得到相同结果。
- 极值、边界值和 45–55 隐藏特质规则有自动化测试。

### 6.2 结果页

- 首屏先展示类型名、原创角色和一条积极但不粉饰的判词；避免把低电量、发疯或犹豫描述为疾病、失败或人格缺陷。
- 展示 3–4 条行为白描、四维分数和一条“牛马护理小贴士”。
- 提供“准吗”反馈，不强制分享。
- 生成适配 9:16 的分享卡；卡片包含产品名和娱乐声明。
- 展示“此刻 → 未知天马”的进化图鉴，除天选牛马外保留剪影/问号；它是探索钩子，不承诺升级收益。
- 提供一个低任务感、带好奇心的“平行世界”主入口，文案使用“去看看”等短句，进入养成世界。

### 6.3 数字生命主场景

- 初始场景为草坪与休息空间，角色是页面唯一视觉主角，也是绝大多数功能的发起者。
- 用户打开产品后直接看见角色的当前行为、环境变化和一条可继续的生活事件，不先看功能菜单。
- 展示电量、发动机、疯感、导航仪的简化状态，不把主页做成仪表盘或多卡片门户。
- 支持点击角色、短对话气泡、空闲动画、场景热点、当前事件和弱化的背包/设置入口。
- 小游戏、留言、动态、任务和访客通过角色邀请、场景物件或事件自然进入，不设置同权重永久导航。
- 低状态时角色呈现“蔫着卖萌”而非绝望或病理化表现。

### 6.4 私密生活流与互动

- 数字生命在用户不操作时也按计划和世界事件持续产生结构化生活事件。
- 用户从主场景上滑或点击相册/信箱等场景物件，查看最近的生活记录；关闭后回到原生活现场。
- 生活记录可包含插画/短视频、短文字、地点、参与角色、相关物品和与过去事件的连续关系。
- 用户可点赞、留言、送出背包物品、保存共同记忆或从一条记录继续互动。
- 首阶段信息流是用户与其数字生命之间的私密窗口，不做公开算法推荐流。
- 支持 AI 牛马作为访客和任务伙伴；真人组队在举报、拉黑、审核和未成年人机制完成前不开放。
- 生活事件的事实由领域状态和事件引擎维护，模型仅负责合规表达和媒体渲染，不得随意改写事实。

### 6.5 物品掉落与接住小游戏

- 物品从屏幕上方掉落，用户通过拖动角色或接取区域收集。
- 物品至少分为食物、玩具、方向道具、金币、任务卡和特殊物品。
- 物品具有类型、稀有度、堆叠上限、有效期、数值影响和是否可消耗属性。
- 掉落概率根据用户最低维度进行温和加权，不制造付费压迫。
- 未接住普通物品不惩罚用户；特殊事件必须提前说明规则。
- 单局目标 30–60 秒，支持触控、键盘和减少动态效果模式。
- 开局使用 3 秒准备倒计时；游戏中展示时间、得分和连击，并允许用户主动暂停、继续或安全退出。
- 连续接住形成最高 10 倍的连击倍率；漏接只清空连击，不扣除已有分数或养成数值。
- 难度通过掉落频率与速度逐步提高，稀有物品必须在颜色之外使用名称/形状等可辨认线索。
- 一局奖励只能结算一次；客户端负责表现，领域状态负责幂等奖励入包。

首版验收：

- 一局可开始、暂停、结束和重新开始。
- 掉落、碰撞、入包、消耗与数值变化形成完整链路。
- 弱网或 Agent 服务不可用时小游戏仍可玩。

### 6.6 背包与消耗

- 显示物品名称、类型、数量、效果、来源与使用条件。
- 使用物品前显示预期影响；重要或稀有物品支持撤销或二次确认。
- 数值更新必须由领域规则计算，前端动画不得成为真实数据来源。
- 消耗前展示会改变的维度和数值；使用后同步呈现角色反应、数值变化和关系反馈。

### 6.6.1 首版养成反馈

- 草坪内保留一条清晰的“今日小事”，由角色气泡或场景物件发起，不做任务列表门户。
- 首版任务为完成一次掉落并把补给带回草坪；完成后只奖励一次关系经验，不设置断签惩罚。
- 点击角色打开轻量互动层，可选择陪伴、对话、投喂或查看共同进展，关闭后回到同一生活现场。
- 关系成长以“同行值”表达，只增加不衰减；它不代表真实情感、心理依赖或人格评价。

### 6.7 休养模式

- 当养成状态持续较低或用户主动选择休息时触发。
- 角色进入帐篷、裹毯子、睡觉或轻松活动。
- 休养期间恢复效率提高，不进行签到损失或任务催促。
- 用户可随时退出，不使用带羞辱感的挽留文案。

### 6.8 数字生命 Agent

- 角色明确表明自己是 AI 角色。
- 支持文字优先，语音输入和语音输出后续加入。
- 记忆分为：用户明确保存的长期记忆、产品状态、短期会话摘要。
- 用户可查看、修改和删除长期记忆。
- Agent 语气温暖、轻松、简短，不说教、不病理化、不替代真人关系。
- 高风险内容进入专门安全流程，不能只依赖模型自由回答。
- 对话默认以场景内气泡、小纸条、生活事件回应或轻量 Sheet 出现，不把标准聊天窗口作为产品主页。
- Agent 必须能引用真实生活事件、物品和共同记忆；不允许编造与领域状态冲突的经历。

### 6.9 视频情绪与 rPPG

该能力不是首个 MVP 的上线阻塞项。

- 必须由用户主动进入功能并单独授权。
- 原始视频默认只在设备端内存中处理，不上传、不落盘。
- 输出使用“表情线索”“趣味心率参考”等措辞。
- 支持无摄像头、拒绝权限和不兼容设备的完整替代流程。
- 心率结果不得用于疾病判断、风险预测或紧急医疗决策。

## 7. 信息架构

首版只有一个产品级主界面：**数字生命生活场景**。

- 首次用户：问卷 → 结果 → 孵化/进入生活场景。
- 回访用户：直接进入生活场景，看到角色当前状态和未完成事件。
- 角色互动：点击角色，在当前场景内打开轻量互动层。
- 生活记录：场景上滑或点击相册/信箱进入；关闭后回到原场景。
- 小游戏：由角色邀请、掉落事件或场景任务进入，不占永久导航位。
- 背包：场景物件入口或使用物品时按需打开。
- 设置与隐私：右上角低权重入口。
- 不使用“生活/动态/游戏/我的”四栏同权重底部导航。

## 8. 核心数据

- User：账号、地区、年龄段声明、同意记录。
- AssessmentSession：题目版本、答案、原始分、标准分、类型、完成时间。
- PetState：四维养成值、心情状态、休养状态、角色皮肤。
- ItemDefinition：物品规则与内容版本。
- InventoryItem：数量、来源、有效期和状态。
- GameSession：掉落种子、得分、接取结果和异常结束原因。
- Mission：任务类型、用户接受状态、完成状态和奖励。
- Conversation：会话与安全分类。
- Memory：用户可见、可编辑的长期记忆。
- ConsentRecord：授权目的、版本、时间、撤回时间。
- DailyPlan：数字生命当天的计划、动机与允许变化范围。
- WorldContext：时间、天气、地点、访客、主题和外部事件的结构化上下文。
- LifeEvent：已规划/发生/呈现/互动/归档的生活事实。
- LifePost：LifeEvent 的用户可消费表达，不作为事实源。
- RelationshipState：亲密、信任、共同经历和互动偏好，不使用惩罚性签到机制。

## 9. 指标

首阶段：

- 问卷开始率、完成率、中途退出题号。
- 结果页“准吗”正向率。
- 内测反馈填写率与“不太像”比例（按题库版本、结果类型做聚合；不得把问卷答案、身份信息或敏感推断用于该指标）。
- 进入养成主页比例。
- 首次小游戏完成率。
- 次日与 7 日回访。
- 权限拒绝后的核心流程完成率。

护栏指标：

- 分享取消率和投诉率。
- 高风险对话转安全流程成功率。
- 敏感权限撤回与数据删除成功率。
- 页面崩溃率、小游戏低帧率比例。

## 10. 素材治理

- 下载目录中的材料只作为候选输入，不自动成为产品事实。
- 每项素材进入仓库前必须确认：用途、版权/授权、版本、是否最终稿。
- 现有 3D 或 AI 渲染角色图只用于理解性格、动作和配色倾向，不作为最终 2D 角色描摹底稿。
- 问卷、文案和规则在进入代码前必须经过产品审计和版本编号。

## 11. 待确认事项

- 8 个角色是否为同一飞马的 8 种状态/皮肤，还是 8 个独立角色。
- 首次登录方式：游客优先、手机号或第三方登录。
- 结果页完整文案和 8 种类型最终命名。
- 首发是否必须包含真实 Agent，还是先用有边界的演示能力。
- 域名、备案主体、隐私政策主体和客服/安全联系人。
