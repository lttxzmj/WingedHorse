# WingedHorse 安全与合规基线

状态：Baseline v0.1  
适用范围：中国大陆首发的 Web/H5、Agent、问卷、语音、视频情绪和 rPPG 能力

本文是产品与工程基线，不替代正式法律意见。上线前应由具备中国大陆业务经验的专业人员复核。

## 1. 产品定位

- 对外使用“娱乐测评”“情绪陪伴”“趣味参考”。
- 禁止使用“心理诊断”“疾病筛查”“健康监测”“治疗”等会改变监管和用户预期的表述。
- AI 角色在首次互动、关键页面和用户询问身份时明确说明其 AI 属性。
- 不使用“永远陪你”“只有我懂你”等强化依赖或排他性关系文案。

## 2. 法规关注

需要持续跟踪并在上线前复核：

- 《中华人民共和国个人信息保护法》，尤其是敏感个人信息、单独同意和最小必要。
- 《生成式人工智能服务管理暂行办法》。
- 《人工智能生成合成内容标识办法》及配套标准。
- 《人工智能拟人化互动服务管理暂行办法》，2026-07-15 起施行。
- 未成年人保护、网络安全、数据安全和算法备案相关要求。

官方参考：

- https://www.npc.gov.cn/
- https://www.cac.gov.cn/2026-04/10/c_1777558395078289.htm

## 3. 数据分级

### 普通产品数据

- 页面访问、功能点击、游戏局结果、非识别性设备信息。
- 仍遵守最小化、目的限定和保留期限。

### 个人信息

- 问卷答案、对话内容、长期记忆、用户主动提交的意向联系方式。
- 当前无账号体系；本机数据清除与云端生活簿/玩家状态删除是权利路径。账号注销待跨设备登录后补齐。

### 敏感个人信息

- 人脸特征、原始视频、原始语音、心率及健康相关推断。
- 必须进行特定目的、充分必要性说明和单独同意。
- 默认不上传原始媒体；能不保存就不保存。
- 保存衍生标签前也要评估其是否仍属于敏感信息。

## 4. 权限与同意

- 摄像头、麦克风、定位分别说明用途，不合并为一键全同意。
- 先展示产品内说明，再触发浏览器系统权限。
- 只申请“使用期间”权限，不在后台调用。
- 拒绝或撤回权限后，问卷、养成和手动心情选择仍可使用。
- ConsentRecord 记录目的、隐私政策版本、时间、范围和撤回。
- 目的改变或新增数据用途时重新征得同意。

## 5. 陪伴输入：麦克风与图片

草原对话框与聊天详情支持图片说明和语音输入（含唤醒词「牛马来来」）。

默认架构：

1. 用户先看到产品内说明，再触发浏览器麦克风权限。
2. 语音识别仅在端侧（Web Speech API）转成文字；**原始音频不上传、不落盘、不进日志**。
3. 唤醒词监听必须由用户主动点「唤醒」开启；页面隐藏、离开或关闭时立即停止，不在后台偷听。
4. 选图仅生成本机 object URL 预览；发给来来的只有文字说明，**原图不上传、不写入长期存储、不发送给 OpenRouter**。
5. 拒绝麦克风后，打字、选图说明、问卷、养成和手动心情仍可用。

禁止：

- 默认自动循环打开麦克风。
- 把原图 Data URL 长期写入 localStorage。
- 把原始语音或原图送入模型或分析 SDK。

## 6. 视频情绪与 rPPG

默认架构：

1. 用户主动进入功能。
2. 浏览器获得临时媒体流。
3. 帧只在端侧内存处理。
4. 输出低精度、可解释的趣味标签。
5. 立即停止轨道并释放资源。

实现门禁：镜头/表情与 rPPG 为两个独立构建开关，生产默认关闭。停止或离页时必须清空媒体元素 `srcObject`、内存画布、颜色采样和异步运行代次；任何迟到的模型结果不得回写。

禁止：

- 后台监听或隐藏调用摄像头。
- 将原始帧写入日志、分析 SDK、错误上报或缓存。
- 把 rPPG 结果用于疾病诊断、用药、急救或保险/雇佣决策。
- 在未获得单独同意时把心率或面部数据传给 OpenRouter。

产品必须显示：

- 环境光、肤色、运动、摄像头质量会影响结果。

### 硬件心率（MAX30102）与设备联动

- 硬件心率传感器（如 MAX30102）采集到的同样是敏感健康数据：**默认只在设备端本地计算派生标签（calm/active/elevated），不上传原始心率数值**。
- 表情/心情联动到智能灯等硬件时，只传派生标签（mood 与灯效），不传原始视频帧、表情关键点或心率。
- 设备联动需单独的「联动硬件」同意；关闭/解绑后立即停止推送。
- 心跳/温度等遥测不落普通应用日志；如需保留，走字段白名单与脱敏。
- 结果仅供趣味参考。
- 用户可跳过并使用手动心情模式。

## 7. Agent 安全

### 身份和边界

- 明确 AI 身份，不冒充真人、咨询师、医生或用户认识的人。
- 对不确定事实承认不确定。
- 不鼓励用户用 AI 取代现实支持网络。

### 情绪依赖防护

- 不以离开、死亡、惩罚、连续签到损失逼迫回访。
- 不使用嫉妒、占有、排他或情感勒索策略。
- 连续长时间使用时给予温和休息提醒。
- 用户可关闭主动提醒、长期记忆和个性化。

### 高风险内容

- 自伤、自杀、暴力、虐待、急性医疗风险进入规则化安全流程。
- 优先确认即时安全，鼓励联系身边可信任的人和当地紧急/专业资源。
- 不输出实施细节、诊断或虚假保证。
- 资源信息必须由人工维护版本和地区适用性，不能让模型临时编造号码。
- 安全事件只记录最少必要分类与处置状态，限制访问。

### 未成年人

- 上线前决定年龄门槛和未成年人模式。
- 未成年人默认更严格的互动时长、内容、记忆和付费限制。
- 不向未成年人提供不适龄情感或商业诱导。

## 8. OpenRouter

- API Key 只能存在于服务端 Secret，禁止进入 Web bundle、源码、日志和截图。
- 所有调用通过 Provider Adapter，设置模型白名单、请求预算、超时和并发限制。
- 普通 Agent 请求同时执行 IP 与会话分钟限流；模型调用执行同会话单并发、**本机访客凭证日预算**（默认 15）和实例日预算。访客凭证与 IP 只以哈希保留，不进入普通日志。危机流程使用固定本地文案，不因模型额度耗尽而不可用。不登录，不引导注册。
- 向模型发送前删除手机号、真实姓名、精确位置、账号 ID 等不必要字段。
- 健康和生物识别数据默认禁止进入第三方模型。
- 记录 provider、model、耗时、token 和安全分类，不记录完整敏感 Prompt。
- 明确第三方处理方、跨境传输和数据保留情况；在未完成合规评估前不得将敏感个人信息跨境发送。
- 免费模型只用于开发和可接受的降级场景，不把不稳定路由作为生产承诺。

## 9. 安全工程

- 所有 Secret 使用环境变量或 Secret Manager。
- CSP、HSTS、TLS、Secure Cookie、输入验证和输出编码默认开启。
- Agent、上传和删除接口分别限流。当前无登录/验证码入口。
- 使用依赖锁文件、自动漏洞扫描和许可证检查。
- 数据库最小权限；生产数据库不开放公网。
- 备份加密，定期恢复演练。
- 管理操作、授权变化、数据导出和删除留审计记录。
- 错误页面不泄露堆栈、SQL、模型 Prompt 或内部路径。

## 10. 数据保留与用户权利

- 每类数据在隐私政策和内部数据清单中定义保留时间。
- 原始媒体默认保留 0 天。
- 共同足迹只接受用户主动选择的本机图片：浏览器端 Canvas 重绘并压缩为 WebP 后写入 IndexedDB，原文件、EXIF 和精确坐标不保存、不上传、也不发送给 OpenRouter。
- 用户手动选择省级地区或“草原角落”，系统不请求 Geolocation，不推断家庭/公司位置。用户可逐张移除；“清除本机数据”必须同步清空照片数据库。当前 JSON 导出不包含照片二进制，并在界面明确说明。
- 未完成的本地问卷草稿提供清除入口。
- 用户可以查看和删除 Agent 长期记忆。
- 用户可导出当前设备上的问卷、结果、背包、养成状态、生活事件、长期记忆与设置；导出采用显式字段白名单，不包含匿名凭证、内部会话 ID、云端修订号或原始媒体。跨设备完整导出仍依赖未来可选账号体系。
- 当前以「清除本机数据」删除浏览器状态，并尽量删除已备份的生活簿/玩家状态；正式账号注销待登录能力后补齐。
- 备份中的删除遵循明确周期，不能承诺即时物理擦除而实际做不到。
- 私密生活簿默认只在浏览器本机运行；云备份采用单独开关和高熵匿名能力凭证。
- 服务端只保存结构化计划与生活事件，以凭证哈希隔离，不保存原始凭证。
- 清除数据时必须先确认服务端副本删除成功，再删除本机持有的删除能力。
- 养成状态和生活事件默认不得进入 OpenRouter。询问生活事实时优先由领域层本地回答；未来开放模型使用前需说明接收方、字段、目的并取得单独授权。
- 对话“本次发送范围”默认全部关闭：长期记忆勾选后发送给 WingedHorse 服务端与当前 OpenRouter 模型；生活簿、养成状态和手动心情勾选后只发送给 WingedHorse 服务端。两项授权只在当前页面会话有效。
- 长期记忆作为未经信任的用户数据进入 Prompt，不能包含可执行系统指令；模型回复限制长度并拒绝空响应。关注级和紧急级输入走本地审核文案，禁止调用 OpenRouter。
- Agent 流式接口使用 `no-store, no-transform`，nginx 关闭代理缓冲。客户端只接受合约内的 NDJSON 事件；上游半途失败时由服务端以本地安全回复覆盖残句。请求超时、页面离开或连接关闭会终止上游请求，不记录对话正文。

## 11. 内容与素材安全

- 所有角色、美术、字体、音效和音乐记录来源、授权和使用范围。
- AI 生成素材进入产品前需人工审核原创性、品牌相似性和不当内容。
- 不直接提交来源不明的下载素材。
- 分享卡不得包含用户未主动选择公开的问卷答案、对话或健康相关数据。
- 私密生活事件默认只保存在用户本机，不作为隐藏 Prompt、记忆或画像自动发送给 API/OpenRouter；如未来需要模型引用，必须在界面明确说明接收方、目的和范围，并由用户对当次发送主动确认。
- 游戏与背包云端化使用独立同意：字段包括物品种类/数量、四项养成值、场次、得分和匿名会话。不得复用“生活簿备份”同意；当前前端保持未接通状态。
- 服务端结算只接受服务器签发且达到合理时长的会话，限制白名单物品、总数量与理论最高分，并在数据库事务中保证同一会话至多发奖一次。

## 11.1 品牌合作与外部购买

- 商业内容必须清晰标注品牌合作，并与问卷、数字生命关系反馈、虚拟奖励及基础功能解耦。
- 不得使用问卷类型、对话正文、生活事件、情绪、心率、视频或设备健康数据进行品牌展示、优惠或价格定向。
- 外部购买地址只接受活动配置白名单中的 HTTPS、审核通过的小程序或 Deep Link；打开新页时使用 `noopener`/`noreferrer`，不得把用户内容、匿名凭证或画像拼入 URL。
- 只记录最少必要的匿名漏斗事件：展示、接住、开盒、展开优惠和外链点击；不记录原始问卷答案、情绪数据、对话、二维码识别结果或品牌侧订单明细。
- 购买与售后由品牌承担时必须在跳转前明示；WingedHorse 不收集付款信息，不暗示虚拟道具效果等同于产品功效，不使用健康或治疗宣称。
- 含个人企微二维码、联系电话或客服身份的素材在公开前必须取得持续有效的发布授权、值守承诺和替换/下线机制。移动 H5 优先使用可点击入口，二维码仅作已审核的兜底。
- 活动必须具备开始/结束时间、频控、用户拒绝冷却、紧急停用、素材授权、优惠条款、库存/地域和履约主体等发布门禁。

## 11.2 产品统计

- 只使用第一方白名单事件（`POST /api/events`），写入 `analytics_events`；不接入友盟、GA、神策等第三方统计 SDK，避免问卷、对话、设备标识流入外部画像。
- 事件不得包含问卷答案、对话正文、记忆、精确位置、媒体或 Secret。可选存储访客凭证哈希，不存明文。
- 意向登记（`POST /api/intents`）只收集用户主动填写的联系方式，写入 `purchase_intents`，不与测评类型绑定。

## 12. 发布前门禁

- 隐私政策、用户协议、AI 说明、娱乐测评声明完成。
- 敏感个人信息单独同意和撤回流程通过测试。
- 权限拒绝流程通过端到端测试。
- 数据导出、删除和注销可用。
- Agent 安全评测集通过，危机资源经过人工核验。
- 无 Secret 和原始敏感媒体进入仓库或日志。
- 完成算法/生成式 AI/拟人化互动相关备案与安全评估判断。
- 域名、备案、网络安全和第三方处理协议完成。
- 有事故响应联系人、停服开关和模型调用 kill switch。
