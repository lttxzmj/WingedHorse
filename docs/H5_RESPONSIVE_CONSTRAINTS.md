# WingedHorse H5 响应式技术约束

状态：强制门禁 v1.0  
适用范围：`apps/web` 的全部用户页面，小游戏为最高优先级。

## 1. 生命线指标

- 320–430 CSS px 宽度内不得出现横向滚动、裁切操作、重叠文字或孤立标题。
- 568–932 CSS px 高度内，首屏主任务必须可见；小游戏进行态不得产生页面滚动。
- 浏览器工具栏展开时，关键操作不得被遮挡；所有底部操作计入 `safe-area-inset-bottom`。
- 页面缩放到 200% 时，非实时游戏页面仍能重排、阅读和完成操作。
- 任何角色、插画、Canvas、视频不得通过不同的横纵缩放填满容器。

## 2. 强制视口矩阵

每次改动首页、问卷、结果、养成或小游戏，至少验证：

| 视口 | 代表场景 | 必须通过 |
| --- | --- | --- |
| 320 × 568 | 极小安卓 / 缩放压力 | 无横向滚动，主操作可达 |
| 375 × 667 | iPhone SE 类短屏 | 标题不裁切，游戏 HUD 与控制不重叠 |
| 390 × 844 | 产品基准 | 视觉验收基线 |
| 412 × 915 | 常见安卓长屏 | 场景比例不被拉长 |
| 430 × 932 | 大屏手机 | 内容不被无意义放大 |
| 844 × 390 | 横屏兜底 | 提示旋转或保持基本可操作 |

桌面只做居中增强，不得反向决定手机构图。

## 3. 页面布局合同

- 文档页使用 `min-height: 100svh`，需要随浏览器工具栏变化时再叠加 `100dvh`。
- 全屏游戏使用 `height: 100svh; height: 100dvh`，内部为“安全区头部 + `minmax(0, 1fr)` 场景”。
- 所有 Flex/Grid 子项在可能收缩处显式设置 `min-width: 0` 或 `min-height: 0`。
- 手机安全边距使用 `max(token, env(safe-area-inset-*));`，不得写死贴边值。
- 页面主容器使用流式宽度与上限；手机不得用固定宽度、整体 `transform: scale()` 或桌面画布缩放模拟响应式。
- 用户可见层级同屏只允许一个主行动；重复的天气、时段、关系阶段和身份标签必须合并。

## 4. 媒体与 Canvas 合同

- 普通图片使用明确的 `width`、`height` 或 `aspect-ratio`，并通过 `object-fit: contain|cover` 保持比例。
- 禁止 `object-fit: fill`，禁止同时强制媒体 `width:100%` 与 `height:100%` 而不保证内外宽高比一致。
- Phaser 使用固定逻辑坐标系，CSS 只允许等比 `FIT/contain`；Resize 后重新计算显示尺寸，不修改角色逻辑尺寸。
- 高分屏 Canvas 的后备缓冲必须覆盖实际 CSS 尺寸乘以设备像素比（最高按 3 倍控制内存），再通过统一场景根容器映射回固定逻辑坐标；不得用 CSS 放大小尺寸 Canvas 冒充 Retina 渲染。
- 动画不得把精灵的绝对 `scaleX/scaleY` 改为 `1`。反馈动画只能基于创建时比例做相对缩放，或只改变位移、透明度、旋转。
- 游戏关键角色在任何纵横比中占场景高度 18%–26%，不能因接住物品或浏览器 Resize 突然放大。
- HUD、引导、控制层属于 DOM 叠层，不进入 Canvas 拉伸坐标系。

## 5. 触控与状态合同

- 触控目标不小于 48 × 48 CSS px，相邻目标净距至少 8 px。
- 实时游戏首选直接拖动；左右按钮是辅助方式，不得遮挡角色或掉落路径。
- Pointer 事件使用 Pointer Capture；页面级滚动区不得绑定高频 `touchmove`。
- 必须覆盖：加载、开始、进行、接住、漏接、连击、暂停、失败、结算、重试。
- `:active` 反馈在 100ms 内可见；持续动画尊重 `prefers-reduced-motion`。

## 6. 文案与结果页合同

- 身份名只出现一次；AI 身份在需要披露的位置清楚说明，不把“数字生命”当作重复装饰标签。
- 状态文案一次只回答一个问题：它在哪里、正在做什么、用户下一步能做什么。
- 测评结果首屏顺序固定为：结果身份 → 一句话解释 → 角色 → 主行动。
- 详细维度、血统、建议采用渐进展开，不得在首屏堆叠多张同权重卡片。
- 游戏结算顺序固定为：结果反馈 → 核心成绩 → 本局获得 → 成长变化 → 回草原；“再来一局”为次行动。

## 7. 自动化门禁

- E2E 对上述竖屏视口检查 `scrollWidth <= clientWidth + 1`。
- 游戏进行态检查 Canvas 外框与内部绘制宽高比误差不超过 1%。
- 检查角色显示框不超过游戏场景高度的 30%。
- 检查 HUD、主操作、返回和底部安全区之间无相交。
- 基准截图必须覆盖首页、倒计时、游戏进行、游戏结算、测评结果。
- `typecheck`、`lint`、关键 E2E 与视觉截图未通过，不得报告 H5 已完成。

## 8. CSS 所有权

- `styles.css` 只放全局 token、基础元素和跨页面组件。
- 页面级构图由页面专属样式表负责；禁止在多个文件重复定义同一页面选择器。
- 新增覆盖前必须先删除或收敛旧规则，禁止靠继续叠加更高优先级修补。
- 页面专属选择器必须以页面根类命名空间开头，避免样式泄漏。
