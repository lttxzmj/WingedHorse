# WingedHorse 实施计划

状态：执行基线 v0.1  
计划原则：先建立可信闭环，再逐步增加游戏、Agent 和感知能力

## Phase 0：文档与仓库基线

交付：

- README 与文档索引。
- 产品需求、技术架构、UI/角色规范、问卷审计、安全合规。
- AGENTS.md、.gitignore、.gitattributes。

退出条件：

- 文档之间的范围、术语和技术选择一致。
- 明确 2D 原创角色方向和素材筛选规则。
- 问卷分数区间问题进入显式决策。

状态：本轮完成。

## Phase 1：工程脚手架

交付：

- pnpm Monorepo。
- apps/web、apps/api、packages/domain、packages/contracts、packages/ui。
- TypeScript strict、ESLint、格式化、Vitest、Playwright。
- 环境变量 schema、Secret 示例文件、GitHub Actions。
- 本地 PostgreSQL/Redis Docker Compose。
- Web 基础路由、错误边界、加载态和移动端壳。

退出条件：

- 一条命令启动 Web/API 和依赖。
- typecheck、lint、test、build 全部通过。
- H5 真机可打开，390 px 无横向滚动。
- 客户端 bundle 中不存在服务端 Secret。

## Phase 2：问卷最小闭环

交付：

- 17 题版本化题库。
- 自动计算可达区间的计分引擎。
- 问卷页、恢复进度、提交和错误处理。
- 8 类型结果模型、结果页与分享卡。
- “准吗”反馈。
- 角色使用原创 2D 占位稿，不使用现有 3D 图作为正式视觉。

退出条件：

- docs/QUESTIONNAIRE_AUDIT.md 的测试全部通过。
- 问卷 → 结果 → 草坪入口端到端零断点。
- 结果固定显示娱乐声明。
- 完成移动端、键盘、屏幕阅读器和长文案检查。

需要用户提供：

- 确认计分修正方案。
- 8 类型最终名称与结果文案终稿。
- 第一只原创 2D 角色的正面或四分之三视角设计稿；如果没有，可先由项目生成视觉探索稿再确认。

## Phase 3：养成与掉落小游戏

交付：

- PetState、ItemDefinition、InventoryTransaction。
- 草坪主页、角色静态/基础动画适配层。
- Phaser 掉落小游戏。
- 食物、玩具、方向道具、金币和任务卡。
- 背包、消耗、数值动画和休养模式。
- 断网、暂停、异常退出和低性能降级。

退出条件：

- 完整跑通掉落 → 接住 → 入包 → 消耗 → 数值反馈。
- 同一 seed 可以复现掉落结算。
- 未接住物品没有惩罚性设计。
- 30 FPS 降级设备仍能完成游戏。

需要用户提供：

- 首批物品清单与文案。
- 草坪、帐篷和道具视觉偏好。
- 角色分层源文件；没有分层文件时先使用静态角色和 CSS/SVG 小动效。

## Phase 4：数字生命 Agent

交付：

- OpenRouter Provider Adapter 与模型策略。
- 文字对话、流式响应、超时和降级。
- 用户可见的长期记忆管理。
- 对话预算、限流、内容安全和危机流程。
- 角色说话/倾听状态与 Agent 事件连接。

退出条件：

- AI 身份清晰可见。
- OpenRouter 不可用时产品可恢复，不影响问卷和游戏。
- 用户可以查看、修改、删除记忆。
- 安全评测集通过，无密钥泄露。

需要用户提供：

- OpenRouter Key 通过安全渠道配置，不发送到聊天或提交 Git。
- 角色人设、称呼、禁用表达和主动提醒偏好。
- 生产模型预算上限。

## Phase 5：语音、视频情绪与 rPPG 实验

交付：

- 手动心情模式先行。
- 浏览器端权限说明和单独同意。
- 端侧表情线索实验。
- rPPG feature flag、兼容性检测和趣味声明。
- 原始媒体不上传的自动化与人工验证。

退出条件：

- 拒绝权限时体验完整。
- 停止功能后摄像头和麦克风轨道立即释放。
- 日志、埋点、错误上报中没有原始帧和敏感正文。
- 法律与伦理复核通过后才可开放生产。

需要用户提供：

- 隐私政策主体、客服与安全联系人。
- 是否保存任何衍生标签；默认不保存。
- 内测用户知情同意文本确认。

## Phase 6：生产部署

交付：

- Docker Compose 生产配置。
- GitHub Actions 构建、部署、健康检查和回滚。
- Nginx/TLS、备份、监控、告警和调用预算。
- 域名、备案、隐私页面、用户协议和运营开关。

退出条件：

- 生产演练、备份恢复和回滚通过。
- 安全/合规发布门禁全部完成。
- 真机、弱网和主流大陆浏览器验收通过。

## 近期执行顺序

1. 初始化仓库并提交本轮文档。
2. 用户确认问卷计分修正与 8 类型文案状态。
3. 搭建 Monorepo 和 CI。
4. 先做问卷 → 结果 → 草坪入口。
5. 再实现掉落小游戏，不等待最终 Rive 动画。
6. 角色原创稿确认后接入统一分层和状态机。
7. Agent 和感知能力分别在独立 feature flag 下推进。

## Definition of Done

每项功能完成必须同时满足：

- 需求和边界写入对应文档。
- 领域规则有测试。
- 正常、空、错、加载、禁用、无权限和弱网状态可用。
- 手机 H5、键盘和减少动态模式通过验收。
- 无 Secret、未授权资产、原始敏感媒体进入 Git。
- 监控、回滚或安全开关与风险相匹配。
