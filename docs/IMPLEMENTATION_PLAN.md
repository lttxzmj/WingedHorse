## Phase 4：数字生命 Agent

交付：

- [x] OpenRouter Provider Adapter、任务模型策略、超时和本地降级。
- [x] 文字对话、回复来源披露和按会话显式选择的数据范围。

- [x] IP/会话分钟限流、同会话并发锁和 UTC 日预算迁移到 Redis 原子操作；Redis 故障时普通请求退回进程限流，模型调用关闭以避免失控费用。
- [ ] 在 OpenRouter 账号侧设置最终费用上限；应用预算不能代替供应商账单级硬限额。
- [x] 角色基础说话/倾听动效与输入、流式回复状态连接，并尊重系统“减少动态效果”设置。
- [ ] 等角色分层源文件到位后，把整体形变升级为嘴型、耳朵、翅膀等局部动作。

## Definition of Done

每项功能完成必须同时满足：

- 需求和边界写入对应文档。
- 领域规则有测试。
- 正常、空、错、加载、禁用、无权限和弱网状态可用。
- 手机 H5、键盘和减少动态模式通过验收。
- 无 Secret、未授权资产、原始敏感媒体进入 Git。
- 监控、回滚或安全开关与风险相匹配。
