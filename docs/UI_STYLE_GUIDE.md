# WingedHorse UI 与角色风格规范

状态：Baseline v0.1  
视觉方向：原创 2D 矢量插画、温暖、幽默、有弹性、角色驱动

## 1. 参考风格如何使用

用户希望角色具有类似多邻国角色的 2D 插画亲和力。本项目只提取抽象方法：

- 轮廓清楚，缩小后仍能认出。
- 表情夸张，姿势能独立表达情绪。
- 色块简洁，阴影克制。
- 角色和产品反馈紧密结合。
- 动画短促、有弹性、可循环。

多邻国官方品牌指南强调角色需要通过有表现力的姿势清晰传达情绪或活动，这一方法适合作为表现力参考：

- https://design.duolingo.com/identity/imagery

### 原创性红线

- 不使用猫头鹰轮廓、Duo 的脸部比例、绿色品牌主色或其标志性姿势。
- 不描摹、多视图复刻或训练性复制多邻国现有角色资产。
- 不复刻其按钮尺寸、图标、课程路径、文案口吻或品牌字体组合。
- WingedHorse 必须通过“飞马/牛马混合身份、翅膀、鬃毛、工作与休养道具、暖金色”形成独立识别。

## 2. 品牌气质

关键词：

- 温暖，不甜腻
- 有梗，不嘲弄
- 活泼，不幼稚
- 柔软，但有行动感
- 情绪丰富，不病理化

视觉叙事：用户来到一块被暖光照亮的小草坪，一只略显笨拙但很有生命力的飞马在这里生活。它不是老师，也不是治疗师，而是会陪用户一起喘口气、接住小物品、慢慢长出翅膀的伙伴。

## 3. 品牌颜色

用户确认的主色板：

| Token | 色值 | 用途 |

| brand-500 | #FFD057 | 主按钮、核心进度、品牌高光 |
| brand-200 | #FFE3A2 | 选择态背景、提示卡、插画辅助 |
| brand-50 | #FFF8DE | 页面暖色底、空状态背景 |
| brand-700 | #D4A21C | 按下态、描边、奖杯与金币 |

补充可访问性颜色：

| Token | 色值 | 用途 |
|---|---|---|
| ink-900 | #3B2E24 | 主要文字、黄底按钮文字 |
| ink-700 | #665548 | 次要文字 |
| ink-500 | #8B7A6C | 辅助说明 |
| surface-0 | #FFFFFF | 卡片与输入表面 |
| surface-50 | #FFFCF4 | 主页面背景 |
| line-100 | #EDE3D3 | 分隔与禁用边框 |
| grass-500 | #58A66A | 草坪、成功状态辅助 |
| sky-500 | #4D8FCB | 信息状态、天空辅助 |
| danger-600 | #C94436 | 错误与高风险提醒 |
| focus-600 | #2E6FC2 | 键盘焦点环 |

规则：

- #FFD057 上使用 #3B2E24，禁止用白色小字。
- 品牌金色不承担错误、成功等语义。
- 8 种类型的专属色需要基于最终原创角色重新设计；现有拼图中的类型色不自动进入正式系统。
- 页面大面积使用低饱和暖白，品牌黄用于强调，不铺满所有表面。

## 4. 字体

首发不依赖 Google Fonts 等境外字体服务。

推荐系统栈：

    -apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif

字号令牌：

| Token | 字号/行高 | 用途 |
|---|---|---|
| display | 36/44 | 结果类型、关键庆祝 |
| h1 | 28/36 | 页面标题 |
| h2 | 22/30 | 区块标题 |
| title | 18/26 | 卡片标题 |
| body | 16/24 | 正文与选项 |
| small | 14/20 | 辅助说明 |
| micro | 12/18 | 声明、标签；不用于关键操作 |

- 中文正文默认 16 px。
- 标题使用 700–800 字重，正文使用 400–500。
- 避免长段居中；问卷题干可居中，选项文字左对齐。
- 结果页梗文案和安全/隐私文案必须形成明显不同的语气层级。

## 5. 布局与响应式

- 以 390 × 844 的手机视口为首要设计基准。
- 内容安全区：手机左右至少 20 px。
- 问卷主体最大宽度 640 px；桌面居中，不把选项拉满屏幕。
- 养成草坪可以全宽沉浸，背包和设置使用受控内容宽度。
- 断点建议：480、768、1024、1280。
- 底部固定操作必须考虑 iOS safe-area-inset-bottom。

间距基于 4 px：

    4, 8, 12, 16, 20, 24, 32, 40, 48, 64

圆角：

- 小控件 12 px
- 选择卡与按钮 16 px
- 主卡片 24 px
- 胶囊仅用于标签、短筛选和状态，不把所有容器做成胶囊

## 6. 深度与线条

风格以扁平 2D 为主，通过少量深度帮助理解操作：

- 普通卡片：1 px 暖灰边线或非常轻的阴影，二选一。
- 主按钮：底部 3–4 px 深色承托，按下时整体下移并缩短承托。
- 弹层：中等柔和阴影，背景遮罩 32–40%。
- 插画阴影：单一光源，最多一层形体阴影和一层落地阴影。
- 不使用玻璃拟态、霓虹、复杂渐变或写实 3D 材质。

## 7. 基础组件

### Button

- Primary：brand-500 背景、ink-900 文字、最小高度 52 px。
- Secondary：surface-0 背景、ink-900 文字、line-100 边线。
- Tertiary：透明背景，用于低优先级操作。
- Destructive：只在确认动作中使用 danger 色。
- 必须覆盖 default、hover、active、focus、disabled、loading。
- 触控目标不小于 44 × 44 px，主操作建议 52 px 高。

### QuestionOption

- 整卡可点，文字区域不得与装饰图标争抢注意力。
- 选中后同时使用描边、背景、图标三种反馈，不能只变颜色。
- 长选项允许自然换行，不截断。
- 选择后不自动瞬间跳题，给用户约 300–500 ms 的确认感或提供下一题按钮。

### Progress

- 显示完成比例和“第 n/17 题”，避免只用颜色。
- 进度变化使用 200–320 ms 动画。
- 不制造“答错”暗示。

### Card

- 同屏只保留一个最高视觉权重的主卡。
- 避免每一段内容都套独立卡片。
- 结果页卡片可导出，但页面中的操作区与导出内容分离。

### Dialog / Sheet

- 手机优先使用底部 Sheet，复杂设置使用全屏页面。
- 关闭按钮、返回手势和 Esc 均可恢复。
- 权限说明必须先解释用途，再触发系统权限弹窗。

### Feedback

- 成功：角色反应 + 简短文字，不只用绿色。
- 错误：就地说明原因与恢复方法，保留用户已输入内容。
- 空状态：说明为什么为空，并给出下一步。
- 加载：优先骨架或角色小动作；减少动态模式显示静态进度。

## 8. 角色设计圣经

### 8.1 角色基础

- 物种：原创圆润小飞马，保留一点“牛马打工人”的笨拙感。
- 识别点：小翅膀、分段鬃毛、宽鼻口、短腿、可变化的耳朵和尾巴。
- 比例建议：头部约占整体高度 38–44%，身体呈圆角梨形，四肢短而有节奏。
- 剪影必须在 64 px 高度仍能识别头、耳、翅膀和身体方向。
- 眼睛负责注视与情绪，嘴和眉只做强化，避免靠文字解释表情。

### 8.2 绘制语言

- 使用闭合矢量形状和清晰色块。
- 主轮廓使用深棕或角色自身的深色，不使用纯黑。
- 同一角色同时出现的主色不超过 4 个，装饰色不超过 2 个。
- 形体阴影比底色深约 8–14% 明度，避免空气感渐变和塑料高光。
- 纹理只用于少量重点道具，不在角色身体铺噪点。
- 翅膀简化为 2–3 个大羽片，确保可绑定和可读。

### 8.3 表情与动作

基础表情：

- neutral：自然呼吸和眨眼
- happy：嘴角上扬、耳朵抬起、身体轻弹
- proud：挺胸、翅膀张开、短暂停顿
- tired：身体略下沉、耳朵放松、眼睑降低
- comfort：靠近、点头或递出小物品
- curious：头部倾斜、眼睛追踪
- surprised：身体拉伸、翅膀快速打开
- resting：裹毯子、睡觉或坐下

禁止：

- 用黑眼圈、病号服、自残意象等表现用户低落。
- 让角色因用户未签到而哭泣、责备或威胁离开。
- 让“疯感”角色表现为危险、失控或污名化精神疾病。

### 8.4 分层交付

每个最终角色至少需要以下独立图层：

- head、body
- left/right ear
- left/right eye、pupil、eyelid
- muzzle、mouth、tongue 可选
- mane front/back
- left/right wing
- front legs、back legs
- tail
- shadow
- accessories

源文件要求：

- 首选 SVG、AI 或可编辑矢量源文件。
- 透明背景，标准正面/四分之三视角，统一画板与锚点。
- 同时交付色板、图层命名、表情表和使用授权。
- PNG/JPG 合成图不能作为可动画最终源文件。

## 9. 动效规范

动效目标是解释状态和增加生命力，不持续抢夺注意力。

时间令牌：

- instant：80 ms
- fast：140 ms
- normal：220 ms
- expressive：360 ms
- celebration：600–900 ms，最多一次

建议缓动：

- UI 进入：ease-out
- UI 退出：ease-in
- 角色反馈：轻量 spring，有一次回弹即可

规则：

- idle 动画每个循环 2–5 秒，加入随机眨眼避免机械同步。
- 用户操作反馈应在 100 ms 内开始。
- 同屏最多一个庆祝动效。
- prefers-reduced-motion 下移除位移、缩放和重复弹跳，保留颜色/静态帧反馈。
- Rive 状态机的公开输入由技术文档定义，设计不得随意改名。

## 10. 页面视觉结构

### 问卷

- 顶部：返回与简洁进度。
- 中部：题干和小型情境插画。
- 下部：纵向选项与下一步。
- 一屏尽量完整看到题干和至少 3 个选项；小屏允许页面自然滚动。

### 结果页

- 第一视觉：类型角色和一句判词。
- 第二层：四维状态与行为白描。
- 第三层：一条小建议、进化钩子和主按钮。
- 分享卡不包含过多操作 UI。

### 草坪主页

- 角色占可视区域约 35–50%，是唯一视觉主角。
- 状态数值弱化为图标或短条，不做数据仪表盘。
- 对话气泡一次只显示 1–2 句。
- 任务、背包和小游戏入口保持清晰但不与角色争抢。

### 掉落小游戏

- 掉落物使用形状、图标和颜色共同区分。
- 避免在动态背景上放小字。
- 暂停、分数和时间位于安全区域，不遮挡掉落路径。
- 碰撞反馈使用短缩放、粒子和音效；任何反馈都提供减少动态/静音替代。

## 11. 可访问性

- 默认达到 WCAG AA 等价对比度。
- 所有交互支持键盘焦点和可见 focus ring。
- 不以颜色作为唯一状态。
- 图片和角色动作提供有意义的 alt/aria 文本；纯装饰隐藏。
- 表单错误与对应字段关联。
- 支持 200% 文本缩放和长中文文案。
- 音频不是唯一信息通道。
- 视频/摄像头能力提供静态替代流程。

## 12. 视觉验收清单

- 灰度下仍能看出主次和可操作区域。
- 角色在 64 px、160 px、320 px 三档尺寸都清晰。
- 黄色按钮文字、辅助文字和禁用状态满足对比度。
- 390 px 宽度无横向滚动。
- 空、错、加载、禁用、焦点、选中、长文案均有设计。
- 减少动态模式可完整使用。
- 与参考品牌进行轮廓和配色对比，确认没有实质性相似。
